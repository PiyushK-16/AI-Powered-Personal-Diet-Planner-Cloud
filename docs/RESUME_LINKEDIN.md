computing coursework project, focused on demonstrating real cloud
architecture patterns rather than just app functionality. The system
includes JWT-based authentication with per-user data isolation, a REST
API backend, a clear separation between a cloud database layer and a
cloud object storage layer, and an AI recommendation engine that
automatically falls back to a local rule-based model if an external API
is unavailable — so the application is never dependent on a paid
service to run. Covered by an automated test suite and documented for
free-tier or enterprise-cloud (AWS/Azure/GCP) deployment.
